Гарын авлага шинэчлэх журам

2026.09.23–11.05-ны хооронд 85 commit хуримтлагдаж гарын авлага хоцорсон. Ийм зүйл дахин гарахгүйн тулд:

  1. 1
    Commit бүрт хэрэглэгчид харагдах өөрчлөлт (шинэ товч, цэс, талбар, алдааны мессеж, имэйл, эрх) орсон бол мессежийн эхэнд [DOC] шошго тавина.
  2. 2
    Сар бүрийн эхэнд git log --grep "\[DOC\]" --since=…-ээр жагсааж, холбогдох модулийн гарын авлагыг шинэчилнэ.
  3. 3
    Шинэчлэх бүрт: «Шинэчилсэн» огноо, бүлгийн тоо, «… шинэчлэлтээр нэмэгдсэн» хэсэг, «Түгээмэл алдаа» хүснэгтэд шинэ мессежийг нэмнэ. Нэр томьёог энэ толиос авна.
  4. 4
    Гарын авлага нь static файл тул модуль upgrade шаардлагагүй. Шинэ гарын авлага / цэс нэмсэн үед л тухайн модулийг upgrade хийнэ.

Файлын байршил: модуль бүрийн static/*_manual*.html; энэ нүүр — vertexmon_tools/static/manuals.html.
