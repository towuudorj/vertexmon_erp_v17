2

KPI ажлын төлөвлөгөө

Цэс: KPI → Ажлын төлөвлөгөө → Миний төлөвлөгөө → Шинэ. Төлөвлөх хугацаа (Улирал / Сар), он, улирал/сарыг сонгоно. Албан тушаал ба Шууд удирдлага ажилтны бүртгэлээс бөглөгдөнө. Нэг ажилтан нэг хугацаанд нэг л төлөвлөгөөтэй.

Төлөв
Төлөвлөж буй→ Батлуулахаар илгээсэн→ Батлагдсан / Хэрэгжиж буй→ Гүйцэтгэл илгээсэн→ Дүгнэгдсэн
  1. 1
    Ажилтан — Төлөвлөгөөт ажлууд табд мөр бүрт Ерөнхий ажил, Хийгдэх ажил, Хийгдсэн байх сүүлийн хугацаа-г бичээд Батлуулахаар илгээх. Удирдлагад «Ажлын төлөвлөгөө батлах» ажил (activity) очно.
  2. 2
    Шууд удирдлага — Багийн төлөвлөгөө-өөс нээж Батлах эсвэл Буцаах (ноорог руу, ажилтанд мэдэгдэл очно).
  3. 3
    Ажилтан — хугацааны турш мөр бүрийн Үр дүн, Төлөв (Хийгдэж байгаа / Бүрэн хийгдсэн), Гүйцэтгэл (%)-ийг шинэчилнэ. Төлөвлөгөөнд ороогүй, удирдлагаас өгсөн ажлыг Бусад ажлын биелэлт табд нэмнэ. Дуусмагц Гүйцэтгэл илгээх — үнэлгээ хоосон мөрүүдэд гүйцэтгэлийн хувь урьдчилан бөглөгдөнө.
  4. 4
    Шууд удирдлага — мөр бүрийн Үнэлгээ (%)-ийг засаж, Удирдлагын тайлбар бичээд Дүгнэх. Буцаавал «Батлагдсан» төлөв рүү очно.

Толгойд Гүйцэтгэл (%), Үнэлгээ (%) (төлөвлөгөөт ба бусад ажлын дундаж) автоматаар бодогдоно. Хэвлэх — «Ажлын төлөвлөгөө, гүйцэтгэл» маягт (ерөнхий ажлаар бүлэглэсэн). Хуулбарлах — өмнөх төлөвлөгөөг шинэ хугацаанд хуулна. Буруу төлөвт орсон төлөвлөгөөг KPI менежер Ноорог болгох-оор сэргээнэ.

3

Даалгавар

Цэс: KPI → Даалгавар → Миний даалгавар (канбан). Хэн ч даалгавар үүсгэж, өөр албанд өгч болно.

ТалбарТайлбар
Гарчиг, Төрөл, Ач холбогдолЭнгийн / Чухал / Яаралтай. Төрөл нь гүйцэтгэх албаар шүүгдэнэ.
Гүйцэтгэх алба, ГүйцэтгэгчГүйцэтгэгчийн сонголтод тухайн албаны ажилтнууд гарна.
Шалгах ажилтанХоосон бол даалгавар үүсгэсэн хүн шалгана.
Ажлын төлөвлөгөөний ажилГүйцэтгэгчийн KPI төлөвлөгөөний аль ажилд хамаарах — төлөвлөгөөн дээрх «Даалгавар» тоонд орно.
Дуусгах хугацааХэтэрвэл «Хугацаа хэтэрсэн» тэмдэглэгдэнэ; хугацаандаа дууссан эсэх бүртгэгдэнэ.

Урсгал: Шинэ → Эхлүүлэх (гүйцэтгэгч; гүйцэтгэгчгүй бол дарсан хүн гүйцэтгэгч болно) → Хийгдэж буй → Шалгуулах (шалгагчид «Шалгана уу» имэйл) → Шалгах → шалгагч Дуусгах эсвэл Буцаах (засвар шаардана). Шалгагч бус KPI менежер Дуусгах (менежер)-ээр хааж болно.

Эрх

Хэрэглэгч (даалгавар үүсгэгч) — өөрийн/албаны даалгавар; Бүх даалгавар харах — бүх даалгавар; Менежер — KPI тохиргоо, ноорог болгох, менежерээр дуусгах.

4

Ажилтны KPI үнэлгээ

Цэс: KPI → Ажилтны KPI. Ажилтан, KPI загвар (сар/улирал/хагас жил), хугацааг сонгоно. Ажлын төлөвлөгөөнөөс тооцох — тухайн хугацаанд гүйцэтгэл илгээсэн / дүгнэгдсэн ажлын төлөвлөгөөний үнэлгээг KPI-ийн «ажлын төлөвлөгөө» ба «бусад ажил» мөрүүдэд татна. Шууд удирдлага Approve хийнэ. Хэвлэх — «Ажлын гүйцэтгэлийг дүгнэх хуудас (KPI)».

5

Илүү цагийн хүсэлт

Цэс: Илүү цаг хүсэлт. Урсгал: Хүсэлт илгээсэн → Зөвшөөрөх (Илүү цаг зөвшөөрөх) → Зөвшөөрсөн → Батлах (Илүү цаг батлах) → Батлагдсан. Батлагдсаныг «Илүү цаг батлах» эрхтэй хүн цуцална.

6

Тушаал ба гэрээ

  • Тушаал (Ажилтан → Тушаал): ноорог → Батлах → батлагдсан; батлагдсаныг цуцлах, цуцалсныг ноорог болгох. Тушаалаас Гэрээ үүсгэх, «Үндсэн ажилтаны гэрээ» / «Туршилтийн ажилтаны гэрээ» экспорт, «Тушаал хэвлэх». Хэвлэх загварыг Гэрээ, Тушаал хэвлэх тохиргоо-оос тохируулна.
  • Бусад гэрээнүүд: батлах, цуцлах, Имэйл илгээх.
  • Сонгон шалгаруулалт: хаагдсан өргөдөл дээр Гэрээ үүсгэх; Ажлын байрны төлөвлөгөө (Recruitment).
  • Сургалтын бүртгэл: ноорог → илгээх → батлах; ХН-ийн шийтгэл оногдуулалт: HR менежер батлана.
7

Ажилчдын хүсэлт ба Сул орон тоо

Ажилчдын хүсэлт бүртгэл

Ноорог → Батлах → HR хянах → ХН Батлах → Захирал хянах → Захирал Батлах → Батлагдсан. Аль ч шатнаас Буцаах / цуцлах; татгалзсаныг ноорог болгоно.

Сул орон тооны захиалга

Ноорог → Батлах → ЗХНАлбаны Захирал Батлах → ҮАХариуцсан Захирал Батлах. Буцаах, цуцлах боломжтой.

8

Ажилтны тодорхойлолт

Ажилтны маягт дээрх Тодорхойлолт гаргах (HR менежер) — Хэл (Монгол / Англи), Тодорхойлолт хүргэх (байгууллагын нэр)-ийг бөглөж Export. Ажлын тодорхойлолт файл гарна. Бусад төрлийн тодорхойлолтыг Тодорхойлолтын бүртгэл-ээр (ноорог → батлах) бүртгэнэ.

9

Шилжилт ба ажлаас гарах

Ажлаас гарах
Тойрох хуудас (илгээх)→ Тойрох хуудас бөглөгдсөн→ Ажил хүлээлгэн өгөх акт→ Ажлаас чөлөөлөх→ Гарсан ажилтны бүртгэл
  • Тойрох хуудас: Илгээх → алба бүр гарын үсэг зурна → Тойрох хуудас бөглөгдсөн → Ажлаас гарах акт үүсгэх → Ажлаас гарахыг батлах.
  • Ажил хүлээлгэн өгөх акт: батлах → дууссаны дараа Ажлаас чөлөөлөх. «Print Work Handover Act Report» хэвлэнэ.
  • Гарсан ажилтны бүртгэл: Ажлаас гарах, Дахин ажилд авч болох, Хар дансанд оруулах.
  • Шилжилтийн бүртгэл: Шилжих, Тушаал үүсгэх.
10

Ажилтны бүртгэл

  • Нас, бусад байгууллагад/компанид ажилласан жил, улсад ажилласан жил, жирэмсний мэдээллийг Update товчоор шинэчилнэ; TTD CHECK — регистрээр ТТД шалгах (HR менежер).
  • Ажлын контакт давхардал: ажилтан бүр өөр ажлын контакттай байх ёстой — нэг контактыг хоёр идэвхтэй ажилтанд холбох боломжгүй. Давхардсан ажилтныг жагсаалтын «Ажлын контакт давхардсан» шүүлтүүрээр олно. Санхүүд харилцагчийн үлдэгдэл буруу хүнд бичигдэхээс сэргийлнэ.
  • Ажилтны маягт → Хэвлэх → Хөрөнгө эзэмшигчийн карт (Үндсэн хөрөнгийн гарын авлага).
